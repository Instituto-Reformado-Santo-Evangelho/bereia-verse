Exibe versículos bíblicos da Almeida Corrigida e Fiel (ACF) em um popup elegante ao selecionar ou passar o mouse sobre referências bíblicas.

== Description ==

O **Bereia Versículos** é uma ferramenta desenvolvida pela Organização IRSE para facilitar o estudo bíblico em blogs e sites cristãos. Ele detecta automaticamente referências bíblicas (ex: João 3:16) e exibe o conteúdo do versículo em um popup moderno, com suporte a temas claro e escuro.

Os direitos de uso da **ACF (Almeida Corrigida e Fiel)** foram gentilmente concedidos pela **Sociedade Bíblica Trinitariana do Brasil (SBTB)** para todas as ferramentas tecnológicas do **Instituto Reformado Santo Evangelho (IRSE)**.

== Installation ==

1. Vá para 'Plugins' > 'Adicionar Novo' no seu painel WordPress.
2. Procure por 'Bereia Versículos'.
3. Instale e ative o plugin.
4. (Opcional) Configure o estilo de marcação em 'Configurações' > 'Bereia Versículos'.

== Frequently Asked Questions ==

= Como o plugin detecta os versículos? =
Ele usa um scanner inteligente que identifica nomes de livros e capítulos/versículos no texto do seu post.

= O plugin é pesado? =
Não. O plugin é extremamente leve e carrega os versículos via API apenas quando necessário.
