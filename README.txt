
# Verse Reader IRSE - Lançamento v1.0.0

## 🪟 Windows
- **Recomendado:** Execute `VerseReader_Setup_1.0.0.exe`. 
- Este instalador configura tudo automaticamente, cria atalhos no menu iniciar e área de trabalho, e já inclui o Java 21.

## 🐧 Linux / 🍎 Mac
- **Universal:** Execute o arquivo `.jar` com o comando:
  `java -jar VerseReaderIRSE-linux-x64-1.0.0.jar`
- **Arch Linux:** Use o arquivo `PKGBUILD` incluído para instalar via pacman (`makepkg -si`).

## Requisitos
- A versão Windows não requer nada pré-instalado.
- As versões Linux/Mac requerem Java (JRE) 21 instalado no sistema.
